# Sistema de Gestión y Trazabilidad de una Central de Esterilización Hospitalaria

Proyecto correspondiente al Trabajo Final Integrador de la Tecnicatura Universitaria en Programación.

## Objetivo

Desarrollar un sistema para gestionar y realizar el seguimiento de los procesos de esterilización de instrumental quirúrgico.

## Estructura

- `docs/`: documentación del proyecto.
- `src/`: código fuente.
- `tests/`: pruebas del sistema.
